# Модуль поиска клиентов по Казахстану (2GIS API + OpenStreetMap Overpass) и WhatsApp Click-to-Chat

Комплексная CRM-система для поиска потенциальных клиентов по Казахстану через официальный API 2GIS и альтернативный источник OpenStreetMap (Overpass API) с персонализированной отправкой предложений разработки сайтов через безопасные ссылки WhatsApp Click-to-Chat.

---

## 🔎 Источники данных: 2GIS и OpenStreetMap (Overpass API)

В модуле поиска организаций доступно мгновенное переключение между двумя источниками:

### 1. OpenStreetMap (Overpass API)
- **Работает без API-ключа** по лицензии ODbL.
- **Оптимизированные запросы:** использует точные пространственные Bounding Box (bbox) для каждого города Казахстана и фильтрацию по OSM-тегам (`shop=hairdresser`, `shop=beauty`, `amenity=cafe`, `amenity=car_wash`, `shop=clothes`, `amenity=dentist` и др.).
- **Строго реальные данные:**
  - Название организации (только объекты с реальными именами, анонимная геометрия отсеивается).
  - Точные географические координаты (`lat`, `lon`).
  - Фактический адрес из OSM-тегов (`addr:street`, `addr:housenumber`).
  - Телефон из тегов `phone`, `contact:phone`, `contact:mobile`, `contact:whatsapp` (если отсутствует — поле остается пустым).
  - Сайт из тегов `website`, `contact:website`, `url` (если отсутствует — статус `NO_WEBSITE_LISTED`).
  - Прямая ссылка на объект на карте: `https://www.openstreetmap.org/node/{id}` или `way/{id}`.
- **Соблюдение ограничений Overpass:**
  - Ограничение частоты запросов (rate limiter) и защита от параллельного флуда.
  - Таймаут 20 секунд с AbortController.
  - Локальное кеширование результатов на 15 минут с возможностью принудительного обновления.
  - Корректная обработка HTTP 429 (Too Many Requests), HTTP 504 (Gateway Timeout) и сетевых сбоев без выдумывания фиктивных данных.
  - Фиксация даты и времени получения данных.

### 2. Официальный API 2GIS (Каталог 3.0)
- Прямой доступ к каталогу `https://catalog.api.2gis.com/3.0/items`.
- Форма настройки ключа с живой проверкой (ping к API) и подробной инструкцией регистрации на [dev.2gis.kz](https://dev.2gis.kz/).

## 🛡 CRM, дедупликация и экспорт в CSV

- **Единая дедупликация:** при импорте из 2GIS или OpenStreetMap система предотвращает дублирование контактов по совпадению нормализованного номера телефона (E.164) или по связке «Название + Город».
- **Фильтрация в CRM:**
  - По городу Казахстана
  - По сфере деятельности
  - По источнику данных (`2GIS`, `OSM`, `DEMO`, `MANUAL`)
  - По наличию телефона (Все / С валидным телефоном / Без телефона)
  - По наличию сайта (Все / `NO_WEBSITE_LISTED` / `WEBSITE_LISTED`)
  - По статусу CRM (`NEW`, `LINK_OPENED`, `SENT`, `INTERESTED`, `REJECTED`, `DO_NOT_CONTACT`)
  - По языку (`RU` / `KZ`)
- **Экспорт в CSV:** экспорт отфильтрованных контактов с поддержкой UTF-8 BOM для корректного открытия кириллицы в Excel со всеми ссылками, координатами, источником и статусами.

## 📱 WhatsApp Click-to-Chat

Каждая организация из любого источника (2GIS / OSM) сразу подключается к Click-to-Chat:
1. **«Открыть WhatsApp»** (безопасный переход, статус переходит в `LINK_OPENED`, без автоотправки).
2. **«Редактировать сообщение»** (живой редактор с предпросмотром URL и сбросом к шаблону RU/KZ).
3. **«Скопировать сообщение»** (копирование в буфер обмена).
4. **«Отметить как отправленное»** (статус `SENT`).
5. **«Заинтересован»** (статус `INTERESTED 🔥`).
6. **«Отказался»** (статус `REJECTED`).
- Защита контактов `DO_NOT_CONTACT` и хронологический аудит действий.

## 🧪 Запуск тестов

В проекте настроено 37 автоматических тестов:
```bash
npm run test
```

Включает:
- `overpassLiveApi.test.ts`: **реальный сетевой запрос** к OpenStreetMap Overpass для кофейных заведений Алматы с проверкой реальных тегов и ссылок OSM.
- `twoGisLiveApi.test.ts`: реальный сетевой тест к production-серверу 2GIS.
- `overpassService.test.ts`: генерация запросов, парсинг тегов, дедупликация, кеширование и обработка ошибок.
- `whatsapp.test.ts` & `rules.test.ts`: нормализация номеров, поддержка казахских букв (`ә, і, ң, ғ, ү, ұ, қ, ө, һ`) и эмодзи (`👋`).
