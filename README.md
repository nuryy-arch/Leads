# Модуль автоматического поиска клиентов по Казахстану (2GIS API) и WhatsApp Click-to-Chat

Интегрированная CRM-система для поиска потенциальных клиентов по Казахстану через официальный API 2GIS и персонализированной отправки предложений разработки сайтов через безопасные ссылки WhatsApp Click-to-Chat.

---

## 🔎 1. Модуль автоматического поиска по Казахстану (2GIS API)

### Возможности:
- **Официальный источник:** интеграция с 2GIS Каталог API 3.0 (`https://catalog.api.2gis.com/3.0/items`) без скрапинга, обхода CAPTCHA и фиктивных данных.
- **Города Казахстана:** преднастроенные регионы и города: Алматы, Астана, Шымкент, Караганда, Актобе, Павлодар, Тараз, Усть-Каменогорск, Семей, Атырау, Костанай, Уральск, Актау, Петропавловск, Туркестан, Кызылорда, Кокшетау, Темиртау.
- **Категории малого бизнеса:** барбершопы, салоны красоты, ногтевые студии, кофейни, кондитерские, автомойки, магазины одежды, цветочные салоны, стоматологии, фитнес-клубы, спа-центры + произвольный поисковый запрос.
- **Получаемые публичные данные:**
  - Название организации
  - Категория (рубрика)
  - Адрес компании
  - Публичный телефон (с автоматической нормализацией в E.164: `77XXXXXXXXX`)
  - Сайт организации (если указан)
  - Прямая ссылка на карточку организации в 2ГИС
- **Статус наличия сайта:**
  - Если сайт указан в источнике: `WEBSITE_LISTED` со ссылкой на сайт.
  - Если сайт не найден: строго статус **`NO_WEBSITE_LISTED`** (не утверждая, что сайта точно не существует, а фиксируя отсутствие сайта в справочнике).

## 🔑 2. Настройка и получение API-ключа 2GIS

Если API-ключ отсутствует, в приложении доступна форма настройки и проверки ключа:

### Инструкция по получению официального ключа:
1. Перейдите на портал разработчиков 2ГИС: [dev.2gis.kz](https://dev.2gis.kz/) (или [dev.2gis.ru](https://dev.2gis.ru/)).
2. Зарегистрируйтесь или войдите в личный кабинет 2GIS.
3. Откройте раздел **«Ключи API»** и нажмите **«Создать ключ»**.
4. Выберите продукт **«Каталог API (Places API 3.0)»**.
5. Скопируйте полученный ключ, вставьте в форму «Ключ API» в приложении и нажмите **«Проверить ключ»**.
6. Приложение выполнит реальный пинг-запрос к `https://catalog.api.2gis.com/3.0/items` и подтвердит статус активации.

## 🛡 3. CRM и дедупликация контактов

- **Устранение дубликатов:** при импорте система проверяет наличие организации в базе по совпадению нормализованного международного телефона или совпадению названия и города.
- **Массовый импорт:** выбор чекбоксами конкретных организаций или кнопка «Выбрать новые» для импорта только уникальных записей.
- **Подключение к WhatsApp Click-to-Chat:** каждая импортированная организация сразу получает персонализированный шаблон (на русском или казахском языке) и готовую Click-to-Chat ссылку.

## 📊 4. Фильтры и экспорт в CSV

В панели управления доступны гибкие фильтры:
- **По городу:** фильтрация по любому городу Казахстана.
- **По категории:** фильтрация по сфере бизнеса.
- **По наличию телефона:** (Все, Только с валидным номером, Без телефона).
- **По наличию сайта:** (Все, `NO_WEBSITE_LISTED` — приоритетные клиенты для предложения сайта, `WEBSITE_LISTED`).
- **По статусу в CRM:** `NEW`, `LINK_OPENED`, `SENT`, `INTERESTED`, `REJECTED`, `DO_NOT_CONTACT`.
- **По языку шаблона:** Русский (RU) / Қазақша (KZ).
- **Экспорт в CSV:** экспорт отфильтрованных строк с кодировкой UTF-8 BOM для корректного открытия в Excel и Google Таблицах со всеми ссылками, контактами и статусами.

## 📱 5. Модуль WhatsApp Click-to-Chat (Сохранен и расширен)

В каждой карточке клиента доступны все 6 кнопок:
1. **«Открыть WhatsApp»** — безопасное открытие вкладки `https://api.whatsapp.com/send/?phone=7...&text=...` без автоматической отправки (статус меняется на `LINK_OPENED`).
2. **«Редактировать сообщение»** — модальный редактор текста перед отправкой с живым счетчиком и генератором URL.
3. **«Скопировать сообщение»** — копирование текста в буфер обмена.
4. **«Отметить как отправленное»** — ручная фиксация отправки (статус `SENT`).
5. **«Заинтересован»** — перевод в статус `INTERESTED 🔥`.
6. **«Отказался»** — перевод в статус `REJECTED`.
- **Защита `DO_NOT_CONTACT`** — исключает случайные повторные отправки тем, кто отказался от коммуникации.
- **Аудит истории** — полная запись всех действий с временными метками.

## 🧪 6. Тестирование проекта

Запуск 31 теста:
```bash
npm run test
```

Включает:
- Автотесты нормализации номеров (`+7 777 456-80-00` -> `77774568000`, `8 (701)...` -> `7701...`).
- Автотесты генерации ссылок на русском и казахском языках с сохранением казахских букв (`ә, і, ң, ғ, ү, ұ, қ, ө, һ`) и эмодзи (`👋`).
- Автотесты дедупликации компаний по телефонам и названиям.
- Автотесты присвоения статуса `NO_WEBSITE_LISTED`.
- Реальный сетевой интеграционный тест к production-серверам `https://catalog.api.2gis.com/3.0/items`.
