# Модуль WhatsApp Click-to-Chat Outbound

Готовое решение для отправки коммерческих предложений потенциальным клиентам через прямые ссылки WhatsApp Click-to-Chat без риска блокировок и без автоматических рассылок.

---

## 🚀 Архитектура и принципы работы

1. **Поиск и ввод контакта:**
   - Система принимает публичный номер телефона в любом формате (`+7 777 456-80-00`, `8 (701) 987-65-43`, `77078889900`).
2. **Валидация и нормализация:**
   - Номер очищается от плюсов, скобок, пробелов и дефисов.
   - Местные префиксы `8 (7xx)` автоматически переводятся в международный формат `7 (7xx)`.
   - Итоговый номер содержит строго цифры: например, `77774568000`.
3. **Персонализация шаблона (RU / KZ):**
   - **Русский язык:** подставляется название бизнеса, ссылки на портфолио и предложение для студии.
   - **Казахский язык:** полноценный казахский шаблон с корректной поддержкой специфических букв алфавита (`ә, і, ң, ғ, ү, ұ, қ, ө, һ`).
4. **Безопасная генерация ссылки:**
   - Формат: `https://api.whatsapp.com/send/?phone=77001234567&text=ENCODED_MESSAGE`
   - Кодирование осуществляется через `encodeURIComponent` без двойного экранирования.
   - Полная поддержка кириллицы, казахских символов, эмодзи (👋, 💅, 💈) и переводов строк (`%0A`).
5. **Безопасный переход в WhatsApp:**
   - Открытие в новой вкладке через `window.open(url, '_blank', 'noopener,noreferrer')`.
   - **Никаких автоматических отправок**: в чат подставляется готовый текст, пользователь сам проверяет его и нажимает кнопку отправки в WhatsApp.
6. **Фиксация действий и защита:**
   - При нажатии «Открыть WhatsApp» фиксируется статус **LINK_OPENED** (ссылка открыта). Статус **SENT** ставится только вручную при подтверждении.
   - Контакты со статусом `DO_NOT_CONTACT` надежно защищены от случайных отправок — генерация ссылки и клик блокируются.
   - Каждое действие сохраняется в хронологической истории аудита.

## 🎛 Интерфейс карточки клиента (Все 6 обязательных кнопок)

В каждой карточке размещены кнопки:
1. **«Открыть WhatsApp»** — открывает подготовленный чат в новой вкладке браузера и переводит статус в `LINK_OPENED`.
2. **«Редактировать сообщение»** — открывает редактор с живым счетчиком символов, возможностью сброса к шаблону и предпросмотром URL.
3. **«Скопировать сообщение»** — копирует готовый текст в буфер обмена для ручной вставки.
4. **«Отметить как отправленное»** — фиксирует статус `SENT` и создает запись в истории.
5. **«Заинтересован»** — фиксирует статус `INTERESTED` (клиент готов к сотрудничеству).
6. **«Отказался»** — фиксирует статус `REJECTED`.

Дополнительно в карточке:
- Переключатель языка шаблона `🇷🇺 RU` / `🇰🇿 KZ`.
- Кнопка «История» с полной хронологией действий.
- Кнопка блокировки «Не беспокоить» (`DO_NOT_CONTACT`).
- Раскрывающийся блок сгенерированного URL.

## 🧪 Запуск тестов

В проекте настроен Vitest с покрытием всех бизнес-требований:

```bash
npm run test
```

Тесты проверяют:
- Нормализацию номеров (`+7 777 456-80-00` -> `77774568000`, `8 (701)...` -> `7701...`).
- Корректность структуры ссылки `https://api.whatsapp.com/send/?phone=...&text=...`.
- Отсутствие двойного кодирования (`%25`).
- Поддержку эмодзи и переносов строк.
- Поддержку казахских букв (`ә, і, ң, ғ, ү, ұ, қ, ө, һ`).
- Поведение статусов при открытии и защиту `DO_NOT_CONTACT`.
